## Technical Requirements
Use the below if project did not specify.

### Backend
1. .NET - Latest LTS version
2. Database - SQLite for PoC, ready to migrate to PostgreSQL
3. Containization by default

### Frontend
1. React - Latest LTS version

## Non Technical Requirements
1. PR MUST be small enough to be humanly reviewable 
2. API need to leave space for future service decopuling, while do not optimize prematurely

## Process Requirements
1. Always use new branch
2. Commit early and often
3. YOLO for files edit within the workspace and branch

## Agentic Approach
1. Always use sub-agent to perform task if possible
2. Use worktree approach when multiple planned work streams is allowed to run in parallel
